## Project Overview

This repository contains the source code for a simple yet elegant food delivery website landing page. It includes navigation, hero section, special dishes, pricing cards, featured items, and a footer. The design focuses on accessibility, easy navigation, and a clear call to action to encourage visitors to place orders.

---

## Features

- **Responsive Navigation:** Easy access to key sections (Home, About, Menu, Contact Us).  
- **Hero Section:** Engaging welcome message with a prominent "Order Now" button.  
- **Specials & Pricing Cards:** Highlight special dishes and pricing options.  
- **Featured Items:** Showcase selected menu items with order buttons.  
- **Footer:** Simple footer with copyright information.  

---

## Technologies Used

- HTML5  
- CSS3 (linked externally in `assest/css/styles.css`)  
- Responsive meta tags for mobile friendliness
